# Product Mission

## Problem

Developers need a comprehensive, hands-on demo that showcases the full capabilities of Spring AI -- from basic chat clients to advanced features like RAG, function calling, guardrails, image processing, and real-time chat. Existing examples tend to show features in isolation, making it hard to understand how they work together in a real application.

## Target Users

Java developers and architects evaluating Spring Boot for AI-enabled applications, conference attendees, and workshop participants who want to see what's possible with Spring AI integration.

## Solution

A Tintin-themed demo application (inspired by the Belgian comic series by Herge) that showcases nearly every Spring AI feature in a single, cohesive, fun application. This is a functional port of the existing Quarkus Langchain4j demo -- same features and domain, rebuilt idiomatically with Spring Boot and Spring AI patterns. The Tintin theme provides engaging domain content -- character analysis, adventure classification, trivia, and RAG over a real Tintin book -- making the demo memorable and entertaining while demonstrating production-ready patterns.
